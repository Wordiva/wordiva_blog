== Description ==

Wordiva Blog Theme is a modern, responsive WordPress theme designed specifically for content marketing and AI-focused blogs. Built with Wordiva's distinctive brand colors (Electric Blue, Royal Purple, Neon Pink, Sunrise Orange, and Golden Yellow), this theme provides an engaging and professional platform for sharing insights about AI, content strategy, and marketing innovation.

Key Features:
* Modern, clean design optimized for readability
* Wordiva brand color palette integration
* Responsive design that works on all devices
* SEO-optimized with structured data markup
* Accessibility-ready with WCAG compliance
* Featured blog post section
* Custom post meta options
* Social sharing integration
* Performance optimized
* Translation ready

The theme is perfect for:
* AI and technology blogs
* Content marketing websites
* Corporate blogs
* Professional portfolios
* Marketing agencies

== Installation ==

1. Upload the theme files to the `/wp-content/themes/wordiva-theme` directory, or install the theme through the WordPress themes screen directly.
2. Activate the theme through the 'Appearance > Themes' screen in WordPress.
3. Use the Customizer to configure theme options and colors.
4. Set up your navigation menus in Appearance > Menus.
5. Configure widgets in Appearance > Widgets.

== Frequently Asked Questions ==

= Does this theme support custom headers? =
Yes, the theme supports custom headers and logos through the WordPress Customizer.

Yes, the theme is fully translation ready with proper text domains and internationalization functions.

Yes, the theme includes RTL language support.
