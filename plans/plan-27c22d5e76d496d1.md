## Implementation Steps

### Phase 1 — Theme: canonicals, titles, robots (`inc/seo-helpers.php`, `inc/seo.php`)

1. **`wordiva_get_canonical_url()`** (new, seo-helpers): centralise canonical resolution.
   - `is_singular()` → `get_permalink()`
   - `is_home()`/`is_archive()` with `get_query_var('paged') > 1` → `get_pagenum_link($paged)` (self-referencing); page 1 → existing term/index URL.
   - Everything else unchanged. `wordiva_seo_meta_tags()` uses the helper for both `<link rel=canonical>` and `og:url`.
2. **`rel="prev"` / `rel="next"`** on paginated home/archives (uses `$wp_query->max_num_pages`), output in `wordiva_seo_meta_tags()`.
3. **SEO title/description helpers** (seo-helpers): `wordiva_get_seo_title($post_id)` → `_wordiva_seo_title` ?: `get_the_title()`; `wordiva_get_seo_description($post_id)` → `_wordiva_seo_description` ?: excerpt/trimmed content (existing logic). Used for `<meta name=description>`, `og:title/description`, `twitter:title/description`, and `BlogPosting.description`.
4. **Title tag** (seo.php): `document_title_separator` → `|`; `document_title_parts` → title part = SEO title override on singular; `site` part = `Wordiva` (constant, `WORDIVA_TITLE_SUFFIX`); update the `' | ' . $site_name` og/twitter titles to the same suffix so `<title>` and og:title match. Tag archive title → `Posts tagged “X”`; home paged → WP adds `Page N` automatically.
5. **Robots** (`wordiva_get_robots_directive`): `is_tag()` with `count < WORDIVA_THIN_TAG_MIN_POSTS (3)` → `noindex, follow`. Paginated pages remain `index, follow`.
6. **Sitemap**: `wp_sitemaps_taxonomies_query_args` filter — for `post_tag`, exclude term IDs with `count < 3` so thin tags leave `wp-sitemap-taxonomies-post_tag-1.xml`. Also remove the dead no-op `wp_sitemaps_users_pre_url_list` closure and wire the existing unused `wordiva_filter_user_sitemap` (or drop it) — tidy-up only.

### Phase 2 — Theme: pagination volume (`index.php`, `inc/customizer.php`, `inc/theme-setup.php`)

## Risks / Considerations

- **Page 2 becomes 404** once 12/page is applied (11 posts). Intended; GSC will report it as “Not found” briefly then drop it. Alternative was noindex — user chose this.
- **`pre_get_posts` on `is_home`** affects the RSS feed? No — guarded with `is_main_query() && is_home() && !is_feed()`.
- **Content edits are production DB writes.** Mitigation: back up `post_content` before `wp post update`; WP revisions retained; slugs untouched.
- **FAQ parser regex on raw block markup** is brittle; the new `core/details` path is the recommended authoring pattern going forward.
- **Not in scope (flagged only):** `index.php` calls `update_post_meta`/`delete_post_meta` during front-end render (lines 86/115) — a write-on-read side effect; recommend removing in a follow-up.
- Title suffix change alters every page’s `<title>`; CTR impact should be monitored in GSC over 2–4 weeks.
